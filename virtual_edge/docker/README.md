### Build From Repo Root Using Docker Compose

**To Build:** *docker compose -f virtual_edge/docker/docker-compose.yml up --build -d*
**To Run:** *docker compose -f virtual_edge/docker/docker-compose.yml up -d*

**Command Window**
*docker compose -f virtual_edge/docker/docker-compose.yml exec virtual_pi sh*
*docker compose -f virtual_edge/docker/docker-compose.yml exec -it virtual_pi /bin/bash* **(Alternative)**
